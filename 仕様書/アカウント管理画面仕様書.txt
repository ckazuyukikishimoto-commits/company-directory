 10: 画面仕様_⑥アカウント管理・パスワード変更

区分	項目	詳細仕様・振る舞い
画面概要	アカウント管理	"管理者だけが使える画面。家族などのアカウントの追加・パスワードの再設定・ロックの解除・有効/無効・管理者の付与を行う。
※アカウントの削除は提供しない（誤操作防止と、削除実行者〈deleted_by〉などの履歴を残すため。使わなくなったアカウントは「無効」にする）。"
	パスワード変更	全員が使える画面。ログイン中の本人が自分のパスワードを変える。
権限	管理者	"・users テーブルに is_admin（BOOLEAN、既定 false）を追加する。管理者は ROLE_ADMIN、それ以外は ROLE_USER を持つ。
・最初の管理者は、Supabase の SQL エディタで次の SQL を1回だけ流して決める（画面からは作らない）。
　update users set is_admin = true where user_id = '（管理者にするユーザーID）';
・管理者以外がアカウント管理画面の URL を直接開いた場合は 403（アクセス権がありません）とする。
・ヘッダーのメニューの「アカウント管理」は管理者にだけ表示する。「パスワード変更」は全員に表示する。"
表示項目	一覧	"・ユーザーID、権限（管理者／一般）、状態（有効／無効／ロック中）、最終ログイン日時
・ロック中は「ロック中（HH:mm まで）」と期限も表示する。
・ソート：ユーザーIDの昇順
・自分の行には「（自分）」と表示する。"
操作	追加	"・入力：ユーザーID、初期パスワード、初期パスワード（確認）、権限（一般／管理者。既定は一般）
・成功時：「アカウントを追加しました」を表示し、一覧に反映する。
・追加したアカウントの初期パスワードは、管理者が口頭などで本人に伝える（アプリはメール等で送らない）。"
	パスワード再設定	"・入力：新しいパスワード、新しいパスワード（確認）
・再設定と同時に、失敗回数を 0 にし、ロックを解除する。
・そのユーザーの「ログイン保持」（RememberMe トークン）をすべて削除する（他の PC の自動ログインも切れる）。
・成功時：「パスワードを再設定しました」"
	ロック解除	"・失敗回数を 0、ロック期限（locked_until）を NULL にする。ロック中の行にだけボタンを出す。
・成功時：「ロックを解除しました」"
	有効／無効の切り替え	"・無効にするとログインできなくなる。あわせてそのユーザーの RememberMe トークンを削除する。
・自分自身は無効にできない（ボタンを出さない。サーバー側でも拒否する）。
・成功時：「アカウントを無効にしました」／「アカウントを有効にしました」"
	管理者の付与／解除	"・他のアカウントを管理者にする、または管理者を外す。
・自分自身の管理者は外せない（管理者が 0 人になるのを防ぐ。サーバー側でも拒否する）。
・権限の変更は、対象のユーザーが次にログインしたときから効く。
・成功時：「管理者にしました」／「管理者を外しました」"
	パスワード変更（本人）	"・入力：現在のパスワード、新しいパスワード、新しいパスワード（確認）
・現在のパスワードが違う場合：「現在のパスワードが違います。」
・成功時：「パスワードを変更しました」。本人の RememberMe トークンのうち、今使っているもの以外を削除する。"
	戻るボタン	名簿一覧画面へ遷移
バリデーション	ユーザーID	"・未入力：「ユーザーIDが未入力です。」
・半角英数字のみ、最大50文字（データ定義に合わせる）：「ユーザーIDは半角英数字50文字以内で入力してください。」
・重複：「このユーザーIDはすでに使われています。」"
	パスワード	"・8文字以上64文字以内（上限はログイン画面に合わせる）：「パスワードは8文字以上64文字以内で入力してください。」
・確認と一致しない：「確認用のパスワードが一致しません。」
・この規則は新しく設定するパスワードにだけ使う（既存のパスワードはそのままログインできる）。"
セキュリティ	共通	"・すべての変更操作は POST で行い、CSRF トークンを必須とする（既存の画面と同じ）。
・パスワードは BCrypt で保存する。画面・ログ・メッセージにパスワードを出さない。
・管理者の判定は画面の表示だけでなく、サーバー側（URL ごとの権限設定）でも行う。"
データ	users の追加列	"・is_admin：BOOLEAN NOT NULL DEFAULT false
・last_login_at：TIMESTAMP NULL許容（ログイン成功時に記録）
・既存のアカウントは、追加時に is_admin = false（一般）になる。"
